description: Investigate a reproducible game defect
---

Read `AGENTS.md`. Reproduce the failure and preserve its exact input, seed,
step, browser or device context. Trace from player input to application,
headless state and the responsible renderer. Identify the root cause with
evidence. Add a targeted regression test if implementing a fix.

Run the relevant local checks and report any browser checks that cannot run.
Never use GitHub Actions.
